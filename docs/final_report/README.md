# Final report (IEEE conference format)

- `paper_final.docx` / `paper_final.pdf`: **the version to submit** (our humanized text, checked and fixed).
- `paper.pdf`: compiled LaTeX report (same content and figures).
- `paper.docx`: Word version in the same two-column IEEE layout (rebuild with `python3 build_docx.py` after compiling the PDF).
- `paper.tex` + `figs/`: source. Upload `overleaf_upload.zip` to Overleaf (New Project > Upload Project) to edit; it compiles with pdfLaTeX.
- `reference_folder/`: the 15 references with DOI links, where to get each PDF, and `references.bib`.
- `VIVA_SHEET.md` / `VIVA_SHEET.docx`: first-person viva notes: key facts, every paper, every formula, likely questions.
